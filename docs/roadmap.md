# Roadmap du Projet — Cartographie MDF

## 🚀 Phase 1 : MVP & Socle Fonctionnel (En Cours / Réalisé)
- [x] Architecture modulaire propre (`frontend/web-cartographie/src`, `backend`, `shared`).
- [x] Cartographie interactive dynamique Leaflet avec clusters et filtres.
- [x] Annuaire complet avec recherche multi-critères et vues Grille/Liste.
- [x] Module de gestion des zones géographiques et affectation des référents.
- [x] Import/Export intelligent Excel avec validation et logs.
- [x] Journal d'audit pour le suivi des actions d'administration.

## 🔮 Phase 2 : Sécurité & Connexion Directe Supabase (Court Terme)
- [ ] Integration Supabase Auth (Connexion Magic Link par e-mail sans mot de passe).
- [ ] Activation des notifications automatiques aux référents lors d'un déménagement d'un membre.
- [ ] Géocodage automatique asynchrone via API gouvernementale ou OpenStreetMap Nominatim.

## 🤝 Phase 3 : Espace Réseau & Interactions Membres (Moyen Terme)
- [ ] Messagerie privée sécurisée entre membres pour l'entraide professionnelle.
- [ ] Publication d'événements associatifs géolocalisés sur la carte.
- [ ] Application Mobile PWA (Progressive Web App) installable sur smartphone.

## 📊 Phase 4 : Statistiques Avancées & Recommandations IA (Long Terme)
- [ ] Dashboard d'analyse démographique et économique de la diaspora.
- [ ] Suggestions IA de mise en relation professionnelle basées sur le profil et la proximité géographique.
